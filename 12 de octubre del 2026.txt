🔍 Analizando jerarquía de cuentas en Windows
La imagen muestra la jerarquía de cuentas y grupos de un equipo Windows (DESKTOP-K5PU4G1). De mayor a menor privilegio:

Nivel	Cuenta/Grupo	Función
1	SYSTEM	Cuenta interna del SO. Tiene control total sobre todos los archivos y servicios.  No es una cuenta de usuario: la usa Windows para ejecutar servicios y procesos internos.
2	Steve (usuario)	Cuenta de usuario individual. Si es miembro del grupo Administradores, tiene acceso elevado sobre el sistema.
3	Administradores (grupo)	Grupo local con control total sobre archivos, configuración, instalación de software y gestión de otras cuentas. 
4	Usuarios (grupo)	Grupo de usuarios estándar.  Acceso limitado: pueden usar programas y sus propios archivos, pero no instalar software ni modificar la configuración del sistema. 

Puntos clave:

SYSTEM no es un "usuario" en el sentido tradicional: no aparece en el Administrador de usuarios y no se puede añadir a grupos.  Sus permisos los gestiona directamente Windows.
Los permisos no son estrictamente jerárquicos en Windows: no funciona como una pirámide rígida, sino como un sistema de permisos individuales asignados a recursos.  Un administrador simplemente pertenece al grupo Administradores, que por defecto tiene permisos amplios sobre casi todos los recursos.
El formato NOMBRE_EQUIPO\Cuenta (ej. DESKTOP-K5PU4G1\Steve) es la notación SAM (Security Account Manager) que identifica cuentas locales. 
En resumen: SYSTEM > Administradores > Usuarios, y cada cuenta de usuario (como Steve) hereda los permisos del grupo al que pertenece.

Acceso de Ollama a archivos locales
Ollama por sí solo no tiene acceso a tu sistema de archivos.  Es solo un generador de texto. Para que Llama 3 "encuentre" y use tus archivos de esa carpeta, necesitas una de estas opciones:

Opción 1: Lo más simple (sin instalar nada extra)
Si solo quieres que el modelo lea un archivo específico, puedes inyectar su contenido en el prompt desde la terminal:

ollama run llama3 "Responde sobre esto: $(cat 'C:\Users\Steve\Desktop\folder de ollama run llama3\mi_documento.txt')"

Funciona, pero solo para un archivo a la vez y con archivos pequeños.

Opción 2: RAG con rlama (recomendado para tu caso)
Es una herramienta en línea de comandos que indexa una carpeta completa y te deja chatear con ella:

# Instalar
curl -fsSL https://raw.githubusercontent.com/dontizi/rlama/main/install.sh | sh

# Indexar tu carpeta (escanea recursivamente todos los archivos)
rlama rag llama3 ollama-docs "C:\Users\Steve\Desktop\folder de ollama run llama3"

# Chatear con lo indexado
rlama run ollama-docs
> ¿Qué contiene el archivo de configuración?

Esto crea un índice vectorial local y el modelo busca los fragmentos relevantes de tus documentos antes de responder. 

Opción 3: RAG con Python (más control)
Si quieres algo más personalizado:

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.llms.ollama import Ollama
from llama_index.embeddings.ollama import OllamaEmbedding

llm = Ollama(model="llama3")
embed_model = OllamaEmbedding(model_name="nomic-embed-text")

# Carga TODO lo que haya en tu carpeta
docs = SimpleDirectoryReader(
    "C:/Users/Steve/Desktop/folder de ollama run llama3"
).load_data()

index = VectorStoreIndex.from_documents(docs, embed_model=embed_model)
query_engine = index.as_query_engine(llm=llm)

print(query_engine.query("¿Qué hay en los documentos?"))

Resumen práctico
Método	Cuándo usarlo
$(cat ...)	1 archivo, rápido, sin instalar nada
rlama	Varios archivos, quieres chatear con ellos sin programar
Python + LlamaIndex	Necesitas control total, pipelines complejos

Para tu caso (una carpeta con documentos y código que quieres que el modelo "encuentre"), rlama es la opción más directa: un comando para indexar, otro para chatear, y listo.

Explained VS Code Workspace Trust
Tranquilo, eso no es nada malo. Es una función de seguridad de Visual Studio Code llamada Workspace Trust (Confianza del espacio de trabajo).

¿Qué está pasando?
VS Code te avisa cuando abres archivos desde una carpeta que no ha marcado como "confiable" antes. Es una protección contra archivos que podrían contener código malicioso (tareas, extensiones, configuración que se ejecuta automáticamente al abrir).

No significa que alguien esté accediendo a tu PC. Simplemente es VS Code diciéndote: "Oye, no conozco esta carpeta, ¿confías en ella?"

¿Qué hacer?
Si es tu carpeta (la de folder de ollama run llama3 o la donde estés trabajando): dale "Open" y marca la casilla "Remember my decision for all workspaces" para que no te lo vuelva a preguntar.
Si es una carpeta de alguien más o no la reconoces: dale "Open in Restricted Mode" (se abre pero sin ejecutar nada automáticamente).
Es tan normal como el "¿Quieres que este sitio guarde tu contraseña?" del navegador. Cero motivo de preocupación.

Diseñé el script de agentes freelance
Te armo un equipo de 3 agentes en un solo archivo. Cada uno es un "rol" con su propio system prompt. Nada más complejo que eso.

import ollama

AGENTES = {
    "1": {
        "nombre": "Copiloto de Código",
        "prompt": "Eres un desarrollador Python senior. Escribes código limpio, comentado y optimizado. Cuando el usuario te da una tarea de automatización, entregas el script completo listo para ejecutar. Usa best practices: type hints, docstrings, manejo de errores."
    },
    "2": {
        "nombre": "Redactor de Propuestas",
        "prompt": "Eres un freelance experto en automatización con Python. El usuario te pega la descripción de un trabajo de una plataforma (Fiverr, Workana, etc.) y tú redactas una propuesta corta, profesional y persuasiva en español. Máximo 10 líneas. Incluye: qué harás, en cuánto tiempo, y por qué eres la persona indicada. Tono: directo, sin humo."
    },
    "3": {
        "nombre": "Documentador",
        "prompt": "Eres un técnico en documentación de software. El usuario te pega código Python y tú generas: 1) un README.md con instrucciones de uso, 2) comentarios inline si faltan, 3) un ejemplo de uso. Formato markdown."
    }
}

def main():
    print("=== EQUIPO DE AGENTES ===")
    for k, v in AGENTES.items():
        print(f"  {k}. {v['nombre']}")
    print("  0. Salir")

    while True:
        print()
        sel = input("Elige agente: ").strip()
        if sel == "0":
            break
        if sel not in AGENTES:
            print("Opción inválida.")
            continue

        agente = AGENTES[sel]
        print(f"\n--- {agente['nombre']} (escribe 'salir' para cambiar) ---")

        mensajes = [{"role": "system", "content": agente["prompt"]}]

        while True:
            user = input("\nTú: ").strip()
            if user.lower() in ("salir", "quit", "q"):
                break
            mensajes.append({"role": "user", "content": user})
            resp = ollama.chat(model="llama3", messages=mensajes)
            print(f"\n{agente['nombre']}: {resp['message']['content']}")
            mensajes.append({"role": "assistant", "content": resp["message']['content']})

if __name__ == "__main__":
    main()

def scraper(url, output="emails.csv"):
    """Extrae emails de una página web y los guarda en CSV."""
    headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"}
    
    try:
        resp = requests.get(url, headers=headers, timeout=10)
        resp.raise_for_status()
    except requests.RequestException as e:
        print(f"Error bajando la página: {e}")
        return

    soup = BeautifulSoup(resp.text, "html.parser")
    emails = set()

    # Busca en mailto:
    for link in soup.find_all("a", href=True):
        if link["href"].startswith("mailto:"):
            emails.add(link["href"][7:].strip())

    # Busca en texto plano (patrón básico)
    import re
    texto = soup.get_text()
    emails.update(re.findall(r"[\w.+-]+@[\w-]+\.[\w.-]+", texto))

    with open(output, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(["email"])
        writer.writerows(sorted(emails))

    print(f"Se encontraron {len(emails)} emails → {output}")

if __name__ == "__main__":

2. portafolio\organizador\organizador.py
import os
import shutil
from pathlib import Path

# Mapeo de extensión → carpeta destino
REGLAS = {
    ".pdf": "Documentos",
    ".txt": "Documentos",
    ".docx": "Documentos",
    ".jpg": "Imágenes",
    ".png": "Imágenes",
    ".mp3": "Audio",
    ".mp4": "Video",
    ".xlsx": "Hojas de cálculo",
}

def organizar(carpeta_fuente):
    """Mueve archivos de una carpeta a subcarpetas según su extensión."""
    fuente = Path(carpeta_fuente)
    movidos = 0

    for archivo in fuente.iterdir():
        if archivo.is_file():
            ext = archivo.suffix.lower()
            destino_carpeta = REGLAS.get(ext, "Otros")
            destino = fuente / destino_carpeta
            destino.mkdir(exist_ok=True)
            shutil.move(str(archivo), str(destino / archivo.name))
            movidos += 1

    print(f"Se movieron {movidos} archivos.")

if __name__ == "__main__":
    import sys
    carpeta = sys.argv[1] if len(sys.argv) > 1 else "."
    organizar(carpeta)

import csv
import sys
from pathlib import Path

def txt_a_csv(entrada, salida="output.csv", separador=","):
    """Convierte un archivo .txt (una línea por registro) a CSV."""
    fuente = Path(entrada)
    if not fuente.exists():
        print(f"No existe: {entrada}")
        return

    lineas = fuente.read_text(encoding="utf-8").strip().split("\n")

    with open(salida, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f, delimiter=separador)
        for linea in lineas:
            writer.writerow([linea.strip()])

    print(f"Convertido: {entrada} → {salida} ({len(lineas)} líneas)")

if __name__ == "__main__":
    entrada = sys.argv[1] if len(sys.argv) > 1 else "datos.txt"
    txt_a_csv(entrada)
