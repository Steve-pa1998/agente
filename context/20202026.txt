TYPE system 
Basic idea

Every value in a program has a type. 
the number 42 is an integer. 
The number 3.14 is a floating point number. 
The text "Hello" is a string. 

A type tells you what kind of thing a value is and what operations make sense for it. 
You can add two numbers you can concatenate two strings. 
But adding a number to a string, what does that even mean? 
That depends on the language, and how a language handles that question says a lot about it´s philosphy. 

In a statically type language like C, Java, or Typescript
The types of all variables are known at compile time before the program ever runs. 

When you declare a variable, you say what type it is. 
This variable holds an integer.
That variable holds a string.
And the compiler checks before the program runs that you never do anything inconsistent, that you never try to multiply a sting by a boolean or pass a number to a function that expects a list.

If you make a type error, the compiler catchces it immediately and refuses to compile the program. 

You fix the error before the program ever executes. 

This is enourmously valuable because it means an entire class of bugs is caught early, automatically, before they can ever casue a problem in a running system. 

The type system acts as a safety net, catching mistakes at compile time that would otherwise become bugs at runtime. 

In a dynamically typed language like python, javascript or ruby varaibales don´t have fixed types. 
A varaible can hold a number one moment and a string the next. 
The types are checked runtime when the code actually executes. 
If you try to add a number to a string in python, you´ll get an error, but you´ll get it when the program runs and reaches that line, not when you compile. 

This makes dynamic languages more flexibil and often faster to write.
you dont have to declare types.
you don´t have to satisfy the compilers type checker.
you can just write code and run it. 

But the price is that certain bugs that a static type system would have caught at compile time slip through and manifest only at runtime, possibly in production, possibly in front of your users this trade-off, 

The trade-off between the flexibilty of dynamic typing and the safety of static typing, is one of the oldest and most hotly debated topics in programming language design. 

and the trend in recent years has been toward a middle ground 

typescript, created by microsoft in 2012, adds a static type system to javascript 
You can annotate your javascipt code with type information, and the typescript compiler  checks it for consistentcy before generating plain javascript. 

Python added optional type hints starting 2014, and tools like mypy can check those hints statically. 
The idea is to get the safety benefits of static typing while keeping the flexibility and ease of use that made dynamic languages popular in the first place. and there´s a deeper story here about what types really are and why they matter so much. 
Because a sophisticated type system dosen´t just catch simple mistakes like adding a string to a number. 
It can express constraints and invariants about your program that the compiler enforces automatically.

In a language like HASKELL, the type system can express the idea that a particular function has no side effects. 
It takes an input and produces an output, and that´s all it does. 
It dosen´t modify any global state. 
It dosen´t write to a file. 
It dosen´t launch a missile.
The type system guarantees it.
and that guarntee, enforces by the compiler, makes the function easier to reason about, easier to test, easier to compose, with other functions. 
It´s not just error chechking.
it´s a form of formal specification, a way of precisely stating what your code promises to do and having the machine verify that it keeps those promises.

This connects on something we touched about in earlier, about functional programming.
In a purely functional language, functions don´t modify state.
They take inputs and produce outputs, and they always propduce the same output for the same input.
They´re like mathamtical functions, predictable, deterministic, no surprises.

And this makes certain kinds of bugs impossible. 
If a funtion can´t modify global state, It can´t introduce the kind of subtle, hard to fin bugs that come two parts of a program modifying the same data in unexpected ways.

import os, json
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",
    api_key=os.environ.get("GROQ_API_KEY")
)

# --- Herramientas ---

def list_files_in_dir(directory="."):
    try:
        return "\n".join(os.listdir(directory))
    except Exception as e:
        return f"Error: {str(e)}"

def read_file(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            return f.read()
    except Exception as e:
        return f"Error: {str(e)}"

def create_file(path, content):
    try:
        os.makedirs(os.path.dirname(path), exist_ok=True) if os.path.dirname(path) else None
        with open(path, "w", encoding="utf-8") as f:
            f.write(content)
        return f"Archivo '{path}' creado."
    except Exception as e:
        return f"Error: {str(e)}"

def edit_file(path, old_text, new_text):
    try:
        with open(path, "r", encoding="utf-8") as f:
            content = f.read()
        if old_text not in content:
            return f"Error: texto no encontrado en '{path}'"
        content = content.replace(old_text, new_text, 1)
        with open(path, "w", encoding="utf-8") as f:
            f.write(content)
        return f"Archivo '{path}' editado."
    except Exception as e:
        return f"Error: {str(e)}"

# --- Tools ---

tools = [
    {
        "type": "function",
        "function": {
            "name": "list_files_in_dir",
            "description": "Lista los archivos en un directorio",
            "parameters": {
                "type": "object",
                "properties": {
                    "directory": {"type": "string", "description": "Ruta del directorio"}
                },
                "required": ["directory"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "read_file",
            "description": "Lee el contenido de un archivo",
            "parameters": {
                "type": "object",
                "properties": {
                    "path": {"type": "string", "description": "Ruta del archivo"}
                },
                "required": ["path"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "create_file",
            "description": "Crea un archivo nuevo",
            "parameters": {
                "type": "object",
                "properties": {
                    "path": {"type": "string", "description": "Ruta del archivo"},
                    "content": {"type": "string", "description": "Contenido"}
                },
                "required": ["path", "content"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "edit_file",
            "description": "Edita un archivo reemplazando texto",
            "parameters": {
                "type": "object",
                "properties": {
                    "path": {"type": "string", "description": "Ruta del archivo"},
                    "old_text": {"type": "string", "description": "Texto a reemplazar"},
                    "new_text": {"type": "string", "description": "Texto nuevo"}
                },
                "required": ["path", "old_text", "new_text"]
            }
        }
    }
]

# --- Prompt del agente (auto-soportado) ---

SELF_PROMPT_PATH = "agents/self.md"

def load_self_prompt():
    """Carga el prompt del agente desde su propio archivo."""
    if os.path.exists(SELF_PROMPT_PATH):
        return read_file(SELF_PROMPT_PATH)
    else:
        default = "Eres un agente útil que responde en español. Puedes listar, leer, crear y editar archivos."
        create_file(SELF_PROMPT_PATH, default)
        return default

def self_optimize(context):
    """
    Meta-loop: el agente lee su propio prompt, analiza qué salió mal,
    y lo reescribe para no repetir el error.
    """
    print("\n🔄 [META-LOOP] El agente está optimizando su propio prompt...")

    current_prompt = read_file(SELF_PROMPT_PATH)

    # Le pides al modelo que se auto-corrija
    meta_messages = [
        {
            "role": "system",
            "content": (
                "Eres un meta-agente que optimiza prompts. "
                "Te van a dar el prompt actual de un agente y un contexto de error. "
                "Tu tarea: reescribe el prompt para que el agente NO repita ese error. "
                "Devuelve SOLO el nuevo prompt, sin explicaciones."
            )
        },
        {
            "role": "user",
            "content": (
                f"Prompt actual:\n---\n{current_prompt}\n---\n\n"
                f"Contexto del error:\n{context}\n\n"
                "Escribe el prompt mejorado."
            )
        }
    ]

    response = client.chat.completions.create(
        model="openai/gpt-oss-120b",
        messages=meta_messages
    )

    new_prompt = response.choices[0].message.content.strip()
    create_file(SELF_PROMPT_PATH, new_prompt)
    print(f"✅ Prompt actualizado en {SELF_PROMPT_PATH}\n")
    return new_prompt

# --- Ejecutor de tools ---

def execute_tool(func_name, func_args):
    if func_name == "list_files_in_dir":
        return list_files_in_dir(**func_args)
    elif func_name == "read_file":
        return read_file(**func_args)
    elif func_name == "create_file":
        return create_file(**func_args)
    elif func_name == "edit_file":
        return edit_file(**func_args)
    else:
        return "Función desconocida"

# --- Bucle principal ---

def main():
    self_prompt = load_self_prompt()
    print(f"🤖 Agente iniciado. Prompt cargado desde {SELF_PROMPT_PATH}\n")

    messages = [
        {"role": "system", "content": self_prompt}
    ]

    while True:
        user_msg = input("Tú: ").strip()

        if not user_msg:
            continue
        if user_msg.lower() == "salir":
            print("¡Hasta luego!")
            break

        # ¿El usuario indica un error? (dispara el meta-loop)
        if user_msg.lower() in ("incorrecto", "mal", "error", "no"):
            context = f"El usuario indicó que la última respuesta fue incorrecta o mala."
            self_prompt = self_optimize(context)
            messages = [{"role": "system", "content": self_prompt}]
            print("🔄 Prompt actualizado. Intenta de nuevo.\n")
            continue

        messages.append({"role": "user", "content": user_msg})

        try:
            response = client.chat.completions.create(
                model="openai/gpt-oss-120b",
                messages=messages,
                tools=tools
            )
        except Exception as e:
            print(f"❌ Error de API: {e}")
            # Dispara meta-loop si fue un error del modelo
            context = f"El agente generó un error de API: {str(e)}"
            self_prompt = self_optimize(context)
            messages = [{"role": "system", "content": self_prompt}]
            continue

        reply = response.choices[0].message

        # Bucle de tool calls
        while reply.tool_calls:
            for tool_call in reply.tool_calls:
                func_name = tool_call.function.name
                func_args = json.loads(tool_call.function.arguments)
                print(f"🔧 {func_name}({func_args})")

                result = execute_tool(func_name, func_args)

                messages.append({
                    "role": "assistant",
                    "content": reply.content if reply.content else "",
                    "tool_calls": [tool_call.model_dump()]
                })
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result
                })

            response = client.chat.completions.create(
                model="openai/gpt-oss-120b",
                messages=messages,
                tools=tools
            )
            reply = response.choices[0].message

        # Respuesta final
        final = reply.content if reply.content else "(sin respuesta)"
        messages.append({"role": "assistant", "content": final})
        print(f"Agente: {final}\n")

if __name__ == "__main__":
    main()

¿Qué hace el meta-loop?

Tú escribes	Qué pasa
incorrecto / mal / no	El agente lee su propio self.md, analiza el error, y lo reescribe
Error de API	Igual, se auto-corrige
Cualquier otra cosa	Responde normal con tools
