#============================================
# DUMP DE PROYECTO - Solo carpeta "agente"
# ============================================

$base = "C:\Users\Steve\Desktop\agente"
$output = @()

# --- CONFIGURACIÓN ---
$extensiones = @(".py", ".md", ".env", ".txt", ".json", ".yaml", ".yml", ".toml")
$excluirCarpetas = @(".vscode", "__pycache__", ".git", "node_modules", ".venv", "venv", ".mypy_cache", ".pytest_cache")
$maxLineas = 200          # Líneas máx por archivo antes de truncar
$maxTamanoKB = 100        # No leer archivos mayores a esto

# --- FUNCIÓN: filtrar carpetas excluidas ---
function Get-FilesFiltrados {
    param([string]$Path)
    Get-ChildItem -Path $Path -Recurse -File | Where-Object {
        $nombreRelativo = $_.FullName.Substring($Path.Length + 1)
        $carpetaExcluida = $excluirCarpetas | Where-Object { $nombreRelativo -like "*\$_\*" -or $nombreRelativo -like "$_*" }
        $extOk = $extensiones | Where-Object { $_.Extension -eq $_ }
        -not $carpetaExcluida -and ($extensiones -contains $_.Extension.ToLower())
    }
}

# 1. ESTRUCTURA (solo archivos relevantes)
$output += "=== ESTRUCTURA ==="
$archivos = Get-FilesFiltrados -Path $base
foreach ($a in $archivos) {
    $rel = $a.FullName.Substring($base.Length + 1)
    $tamano = [math]::Round($a.Length / 1KB, 1)
    $output += "$rel ($tamano KB)"
}
$output += ""

# 2. CONTENIDO DE CADA ARCHIVO
foreach ($a in $archivos) {
    $rel = $a.FullName.Substring($base.Length + 1)
    if ($a.Length -gt ($maxTamanoKB * 1024)) {
        $output += "=== $rel === [OMITIDO: $([math]::Round($a.Length/1KB)) KB > $maxTamanoKB KB]"
        $output += ""
        continue
    }
    $output += "=== $rel ==="
    $content = Get-Content $a.FullName -Raw -Encoding UTF8
    $lines = $content -split "`n"
    if ($lines.Count -gt $maxLineas) {
        $output += $lines[0..($maxLineas-1)] -join "`n"
        $output += "... [TRUNCADO, $($lines.Count - $maxLineas) líneas más]"
    } else {
        $output += $content
    }
    $output += ""
}

# 3. .env (SIN valores)
$envPath = Join-Path $base ".env"
if (Test-Path $envPath) {
    $output += "=== .env (solo nombres) ==="
    Get-Content $envPath | Where-Object { $_ -match '^\s*\w+' } | ForEach-Object {
        ($_.Split('=')[0]).Trim()
    }
    $output += ""
}

# 4. SALIDA
$final = $output -join "`n"
$final | Out-File "$base\_dump.txt" -Encoding UTF8
Write-Host "✅ Dump generado: $base\_dump.txt" -ForegroundColor Green
Write-Host "   Archivos incluidos: $($archivos.Count)" -ForegroundColor Cyan
Write-Host "   Tamaño total: $([math]::Round(($final.Length / 1024), 1)) KB" -ForegroundColor Cyan

¿Qué cambió?
Problema antes	Solución
Juntaba todo (.vscode, __pycache__, etc.)	$excluirCarpetas filtra las carpetas de ruido
Sin filtro de extensión	Solo lee .py, .md, .env, .txt, .json, .yaml, .yml, .toml
Un archivo de 15K líneas lo volcaba completo	$maxTamanoKB = 100 → si pesa más, lo omite con aviso
Truncaba a 150 líneas fijas	$maxLineas = 200 (ajustable arriba)
No sabías cuántos archivos entraron	Al final imprime conteo y tamaño del dump

Para ajustar:
Agregar/quitar extensiones → edita $extensiones
Agregar carpetas a excluir → edita $excluirCarpetas
Más/menos líneas por archivo → cambia $maxLineas
Con esto ya no te va a pasar un VS Code de 15K líneas por error. 🚀

¿Dónde se guarda?
La línea que decide es esta:

Eso lo guarda en → C:\Users\Steve\Desktop\agente\_dump.txt

Sobre tu _dump.txt de anoche
Out-File sobrescribe (no duplica). Así que si lo corres, te va a reemplazar el de anoche, no creará un segundo archivo.

Si quieres conservar el de anoche y generar uno nuevo, cambia esa línea a:

$nombre = "dump_" + (Get-Date -Format "yyyyMMdd_HHmm") + ".txt"
$final | Out-File (Join-Path $base $nombre) -Encoding UTF8

Ahora te va a guardar algo como dump_20261031_1432.txt y no pisa el anterior. 🫶

Antes (derecha)	Ahora (izquierda)

1. Tu observación sobre el tiempo invertido → Es correcta y tiene nombre
Lo que acabas de decir:

Eso es exactamente la Paradoja de Loschmidt (1876).  Y tu punto clave —"el mapa debería ser visible"— es el que le rompió el sueño a Boltzmann:

El problema: El Stosszahlansatz dice "antes de colisionar = no correlacionado." En reversa, eso se convierte en "después de colisionar = no correlacionado." Pero en reversa, las partículas que "salen" (que en el tiempo normal "entraron") SÍ están correlacionadas. Contradicción. 

Tu insight: "El mapa de su estructura debería ser visible" → Sí. La correlación está codificada en la distribución conjunta (se llama f₂, vive en un espacio de 12 dimensiones para 2 partículas).
