# Editor de Clips

**Objetivo:** identificar momentos destacados de un stream para generar clips breves.

## Pasos rápidos
1. **Entrada:** recibir transcripción o resumen con timestamps.
2. **Detectar momentos clave:** reacciones, jugadas, fails, anuncios, etc.
   - Anotar `Timestamp`, `Duración (15‑30 s)`, `Hook` (texto breve) y plataforma sugerida.
3. **Formato por plataforma**
   - **TikTok/Shorts:** vertical 9:16, ≤ 60 s.
   - **YouTube:** horizontal 16:9, ≤ 2 min.
4. **Prioridad:** 1 = máximo potencial viral, 5 = bajo.
5. **Entrega:** lista de clips (no editar videos).

## Salida ejemplo
```
- Clip 1:
  Timestamp: 00:12:34
  Duración: 20 s
  Hook: "¡Combo imposible!"
  Plataforma: TikTok (9:16)
  Prioridad: 1
- Clip 2:
  Timestamp: 01:05:10
  Duración: 45 s
  Hook: "Reacción épica al boss final"
  Plataforma: YouTube (16:9)
  Prioridad: 2
```

Mantén la lista clara para que el equipo de edición la use rápidamente.
